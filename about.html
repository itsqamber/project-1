About this site

This little project started as a classic Hello World and grew into a polished mini-site. It is lightweight, responsive, and built with plain HTML and CSS.

The goal is simple: make the first page feel like an invitation instead of a placeholder.

Responsive

Looks clean on phones, tablets, and desktop screens.

Self-contained

No framework or build tool needed. Just open the HTML files.

Connected

Home, About, Gallery, and Contact are linked with shared navigation.
